# React Webplatform Templates

This project contains a collection of React components and templates for building various web platform interfaces. Each template is designed to be reusable and customizable to suit different project requirements.

## Installation

To use these templates in your project, simply follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/Alex-Gichau/alex-react-templates.git
   ```

2. Navigate to the desired template directory:

   ```bash
   cd alex-react-templates/<template-name>
   ```

3. Install dependencies:

   ```bash
   npm install
   ```
